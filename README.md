# CyberSec Notes

Repositório pessoal de estudos em Segurança da Informação, com foco em:

- Web Application Pentesting
- Bug Bounty
- Pentest de infraestrutura
- Reconnaissance
- Linux e Windows
- Ferramentas ofensivas
- Metodologias de teste

O objetivo deste repositório é documentar conceitos, técnicas, ferramentas, erros cometidos em laboratórios e metodologias que eu possa reutilizar durante minha evolução na área de segurança ofensiva.

> Todo conteúdo prático deste repositório é destinado exclusivamente a laboratórios, CTFs, ambientes próprios ou sistemas com autorização explícita para testes.
